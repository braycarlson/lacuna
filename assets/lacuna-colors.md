# lacuna colors

Each file is drawn in one ink, and each icon tile is one flat color.

## On Dark

| Use | Color |
|---|---|
| Icon tile | `#16181F` |
| Ink | `#F4F5F7` |

## On Light

| Use | Color |
|---|---|
| Icon tile | `#F4F5F7` |
| Ink | `#16181F` |

## Mono

A mono file without a ground fills each shape with `currentColor`, so an inline copy takes the
color of the text around it.
