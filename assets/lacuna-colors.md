# lacuna colors

Each stop is listed with its offset, and each row names the direction its gradient runs.

## On Dark

The full-color files use the Onibi colorway. Its ink is light, so it has no on-light version; the mono files cover light grounds.

| Use | Stops |
|---|---|
| Mark, top to bottom from y 0 to y 322 in the mark's own units (377 wide, 307 tall) | `#BFF4EE` at 0, `#3A6BFF` at 1 |

| Use | Color |
|---|---|
| Icon tile and ground | `#1C1A2B` |
| Wordmark | `#BFF4EE` |

## Mono

| Use | Color |
|---|---|
| Ink on light, icon tile and ground on dark | `#0C0C0C` |
| Ink on dark, icon tile on light | `#FFFFFF` |

A mono file without a ground fills each shape with `currentColor`, so an inline copy takes the color of the text around it.
